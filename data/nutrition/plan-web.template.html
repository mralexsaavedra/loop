How to use it

Inside each table, every option is worth the same. Pick the food you fancy and look at its grams — the day total does not change. For protein, lean green every day; leave the red for treats. Count the fat added by oily carbs.
Example cutting plan (~2.150 kcal/day average). Replace these foods, targets and notes with your own data in plan-data.json, then run npm run generate.
